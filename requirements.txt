# CSS minification at deploy time (manage.py minify_css, after collectstatic).
# Pure Python, so the droplet gains no Node runtime. Chosen over clean-css after
# measuring on this codebase's 11 stylesheets: rcssmin lands within 10 BYTES of
# clean-css -O2 network-wide, while only stripping comments and whitespace — it
# cannot reorder a rule and silently break one of eight themes. Worth 7.3 KB
# (-37%) of brotli'd CSS on the flagship's first paint.
