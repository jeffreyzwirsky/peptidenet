The vetting criteria

Five things a supplier should be able to prove.

This is the checklist we built the directory around. Run it against us, then run it against whoever else is in your browser tabs. We fail the first three.

1 · A stated release threshold

A supplier without a published number has nothing to fail against. We publish no number, because we hold no data that would support one.

2 · Independent testing

Purity and identity data, run outside the seller's own building. In-house-only data is a marketing asset, not a control. We hold no such data, in-house or otherwise.

3 · A lot-matched certificate

The certificate's lot number must match the vial's. Reused certificates are a common failure among the listings we've reviewed. We issue no certificate at all.

4 · A published delivery window

{{ site.shipping_window }}, direct from our manufacturing partner, tracked. A real window beats an unverifiable promise of speed every time. This one we do meet.

5 · A reachable human

An email address and phone number that answer questions before you buy — and still answer after you have. Ours are at the bottom of this page.
